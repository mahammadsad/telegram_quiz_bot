# Community code of conduct

Be respectful, specific, and learner-focused. Harassment, discrimination, threats, doxxing, sexualized conduct, deliberate misinformation, exam cheating, and disclosure of private learner or security data are not acceptable.

Report conduct concerns privately through the repository owner’s GitHub contact. Enforcement actions may include a warning, content removal, temporary restriction, or permanent exclusion. A named independent escalation contact remains to be established.
