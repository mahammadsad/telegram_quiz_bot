# Public roadmap

## Trust and reliability

- One verified production URL and Telegram launch path
- 13/13 daily-subject completeness with dead-letter alerting and reserve inventory
- Server-authoritative ranking time and anomaly review
- Evidence-based question verification and multi-source current affairs

## Learning product

- Discoverable mock, sectional, and PYQ catalog
- Exam blueprint, diagnostic, syllabus progress, daily plan, revision, mock analysis
- Bengali-complete localization before additional languages
- Opt-in reminders with quiet hours and unsubscribe

## Operations and community

- Role-based operations console, SLOs, traces, and incident runbooks
- WCAG 2.2 AA automated and manual checks
- Privacy export/deletion and retention automation
- License and content-rights decision by the repository owner

Progress is tracked in `docs/AUDIT_REMEDIATION_STATUS.md`; an item is complete only with test or deployment evidence.
